      Data pusat / panitia

      Cara cepat: impor paket foto (file .json dari panitia). Foto tidak disimpan di situs, hanya diproses di perangkat ini.

      Jika file tamu.json di-upload ke repository GitHub Pages, aplikasi akan mencoba memuatnya secara otomatis saat dibuka. Siapkan data dari PC/laptop: daftarkan foto, klik Ekspor data (.json), lalu upload file tamu.json ke root repository.
